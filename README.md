# SERP Preview

En enkel React-applikation som låter användare skapa och **förhandsgranska Google-liknande sökresultat (SERP)** i realtid. Perfekt för SEO-testning och innehållsförhandsvisning innan publicering.  

---

## **Funktioner**

- Dynamisk förhandsvisning av **titel, URL och meta-beskrivning**  
- Realtidsuppdatering när användaren skriver  
- Responsiv layout som efterliknar Googles SERP  
- Enkel **komponentbaserad arkitektur** (React + JSX)  

## **Struktur**

Projektets filstruktur ser ut så här:

src/:
- App.jsx (Huvudkomponenten som renderar applikationen)

components/:
- Header.jsx        : Sidhuvud / titel
- InputFields.jsx   : Formulär för titel, URL och beskrivning
- GooglePreview.jsx : Förhandsvisning av SERP-resultatet

## **Användning:**

- Skriv in titel, URL och beskrivning
- Se förhandsvisningen uppdateras i realtid
- Kopiera resultatet till din webbsida
